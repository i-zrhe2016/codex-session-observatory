## 观察范围与格式依据

启动参数指定扫描目录，真实验收目录为 `~/.codex/sessions`。只读取该目录内的 JSONL，不采集其他目录，不修改输入。目标包括用户与助手可见正文、可见代理通信、工具调用与结果；system/developer 上下文折叠显示。密文不解密，不推测不可见正文或隐藏推理。

首版只承诺支持仓库既有 fixture 和已观察的 Codex 0.163.0 格式，其他格式显式提示支持受限。前期只读抽样涉及 10 份 0.163.0 日志，均为 `history_mode=paginated`；这只是格式调查，并非动态采集或浏览器验收。观察到的结构包括：

- `session_meta` 中的 `id`、`session_id`、`parent_thread_id`、`source`、`agent_path` 等关系信息。
- `event_msg` 的 `task_started`、`task_complete`、`turn_aborted`、`item_completed`。
- `response_item` 的 message、agent_message、reasoning、function_call、custom_tool_call 及相应 outputs；以及 `token_usage_record`、`turn_context`。
- `item_completed.item` 中的 `AgentMessage`、`UserMessage`、`CommandExecution`、`SubAgentActivity`、`CollabAgentToolCall`、`Plan`、`ContextCompaction`、`FileChange`。

这些是观察到的候选输入，不意味着每个字段的语义均已确认。真实 ID 的线程、运行与事件含义，以及同一事实的多种表达，必须由合成和真实样本核对后实现；歧义不得靠猜测补全。日志正文、凭据和个人资料不进入仓库或验收文档。

## 采集与标准化设计

新增入口：`python3 observe.py --sessions-dir PATH --port 8765`，仅绑定 `127.0.0.1`。每 2 秒发现新 JSONL，每 1 秒增量读取；浏览器每 1 秒轮询只读接口。

每个文件缓存字节偏移和未完成行，等待完整行后再解码、解析，正确处理跨次读取的 UTF-8 字节和半行。截断或替换时重建该文件派生数据、提升数据代次并重置客户端游标。不能用旧偏移续读新文件，也不能让客户端继续使用失效游标。

标准化事件至少保留会话/线程身份、轮次、事件 ID、时间、类型、角色、内容和来源路径/行号；运行 session ID 单独保留。按明确 ID 合并同一事实的重复表达，并保留全部来源；没有明确证据的相似文本不去重。工具 `call_id` 在线程内隔离，不能跨线程配对。未知结构、损坏记录和身份冲突进入数据质量提示，不静默吞掉。

依据 thread ID、`parent_thread_id` 和明确子代理事件建立代理树；缺失或冲突关系标记为“未关联”，不按文件名、时间接近或文本相似猜测父子关系。

失败识别与累计 tokens 语义沿用现有分析器：只认明确结构化或已支持包装信号，不以任意输出关键词判失败；累计 usage 快照不求和，不重复加缓存 tokens。新增 usage 结构只有在语义确认后才补充，同一事实不重复计数，不猜测父子总 tokens。已有 `analyze.py` 的 CLI 行为不改变。

## 状态与可解释性

以明确事件判定轮次开始、完成、中断或失败；后续新轮次恢复活动状态。工具失败与轮次失败分别展示，工具失败不能自动升级为轮次失败。

顶部展示最后有记录的轮次状态、未返回工具、最近事件时间、静默时长、tokens 与采集健康。未返回工具、日志静默和采集失败是独立事实；没有日志不能判定卡死、等待审批或进程退出。所有状态均应能追溯到来源记录，缺少证据时显示未知或记录不足。

## 浏览器界面与只读接口

左侧为会话列表和代理树；中央按轮次展示完整可见对话、进度及工具；右侧显示选中事件的参数、输出、失败证据与来源。支持类型、代理、失败筛选，以及已加载文本搜索，明确搜索范围。

历史事件每页 200 条。长正文分段加载，显示尚有内容并允许继续读取，不静默丢弃或截断。默认滚动跟随；用户上翻后暂停跟随并显示新增数量，可恢复跟随。刷新页面保留选中会话。代理树可跳转关联会话，未关联项单独展示。

只读 JSON 接口提供会话列表、会话 snapshot、带游标的事件分页和单事件正文。游标包含数据代次；重建后返回明确的游标失效信号，客户端重新获取 snapshot 和事件。Ticket 间先固定这些接口的请求、响应、错误及重置语义，再开发 UI。

仅允许预期的本机 Host/Origin，拒绝不匹配请求；防止路径遍历和越界符号链接访问，客户端不能任意指定服务器文件路径。正文以纯文本安全呈现，避免 HTML/脚本注入。不提供执行命令、发消息、审批或修改会话的能力。
